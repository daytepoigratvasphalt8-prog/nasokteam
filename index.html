Nasok Server

В разработкеБесплатно

Свой сервер Minecraft прямо на твоём компьютере. Запустил, дал друзьям IP — и вы играете вместе.

  • Без хостингаСервер работает на твоём ПК, платить за VPS не нужно.
  • Вход по IPНикаких доменов: друзья подключаются по адресу.
  • Полностью бесплатноНи подписок, ни платных функций.
  • Вместе с лаунчеромСтавится через Nasok Installer рядом с Nasok Launcher.
